Autonomous Web Research Agent

A multi-agent research microservice. Give it a topic — a planner decomposes it, parallel workers search, scrape and parse the live web, a critic bounds coverage gaps, and a writer produces a citation-verified report behind a human review gate.

Multi-agent pipeline

Planner → parallel search/scrape/parse workers → bounded critic loop → writer → output guardrail → HITL gate.

Untrusted-content defense

Scraped pages are sanitized before reaching the LLM — indirect prompt injection embedded in web content is neutralized.

Evaluation-driven

Versioned dataset, deterministic evaluators and a CI quality gate (citation support, source precision, topic coverage).

Production posture

JWT auth, rate limiting, SSE progress, SQLite checkpoints, Prometheus metrics, structlog, per-job cost tracking.
